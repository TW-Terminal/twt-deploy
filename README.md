# TWT Deploy
一個在 [TW-Terminal](https://twt.illusd.com) 上運行的官方部署指令開源倉儲

## 目前尚未發布正式版  |  敬請期待

## 什麼是TWT Deploy
TWT Deploy 是一個開源的命令儲存庫，僅在 TW-Terminal 上運作

--

你部署完成的將會在 t.illusd.com/ 公開

## 如何使用
你可以在 TW-Terminal 中輸入命令

**``` tw 下載 部署 ```**
或
**```tw install twt-deploy```**
